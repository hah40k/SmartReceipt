# SmartReceipt

Локальное приложение для анализа расходов через фото кассовых чеков.
Работает полностью офлайн — никаких облаков, финансовые данные не покидают машину.

Фотографируешь чек → ИИ читает и классифицирует товары → всё сохраняется в локальную базу →
советник отвечает на вопросы о бюджете и составляет список покупок.

**Стек:** Python 3.11 · Qwen3.5:9b · Ollama · SQLite · Gradio
